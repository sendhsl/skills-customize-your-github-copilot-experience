
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. You'll create a Hangman game where players guess letters to reveal a hidden word before running out of attempts, practicing string manipulation, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Create the Hangman Game

#### Description
Develop a fully functional Hangman game in Python. The game should randomly select a word from a predefined list and allow players to guess letters one at a time. Display the current progress of revealed letters and track the number of incorrect guesses remaining.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and display current progress in underscore format (_ _ _)
- Track incorrect guesses remaining and display them to the player
- End the game when the word is guessed or attempts are exhausted
- Display appropriate win/lose messages with the final word revealed
